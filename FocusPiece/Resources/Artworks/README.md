# Artworks

The eight paintings are **not** committed (they are large Public-Domain JPGs
from Wikimedia Commons). Run the fetch script from the repo root to download
and bundle them:

```sh
./Scripts/fetch_artworks.sh
```

Until they are present, the app shows a calm placeholder in their place — it
still builds and runs. Expected base names (loaded via `Artwork.assetName`):

- `Almond_blossom`
- `Tsunami_by_hokusai_19th_century`
- `Van_Gogh_-_Starry_Night_-_Google_Art_Project`
- `Caspar_David_Friedrich_-_Wanderer_above_the_sea_of_fog`
- `Red_Fuji_southern_wind_clear_morning`
- `Claude_Monet,_Impression,_soleil_levant`
- `Gustav_Klimt_016`
- `Pieter_Bruegel_the_Elder-_The_Harvesters_-_Google_Art_Project`
